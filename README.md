# [NAME] Studio: site + admin

The agency landing page with an editing admin, built the same way as the portfolio: **Next.js + Payload CMS** in one codebase. Every word, image, colour and the section order is editable at `/admin`.

The public page is still plain server-rendered HTML with the original CSS and one small script (`public/site.js`, ~6 KB). No React is sent to visitors.

## Running it locally

```bash
npm install
npm run seed    # loads site/content.json into the database + creates your login (safe to re-run)
npm run dev
```

- Site: http://localhost:3000
- Admin: http://localhost:3000/admin

Login: `cam@polarcreativegroup.com`. The password is `SEED_ADMIN_PASSWORD` in `.env`. Change it under **Account** in the admin. "Forgot password?" won't send email until an email service is set up.

## What you edit, and where

| In /admin | Controls |
| --- | --- |
| **Dashboard** | Every section at a glance: live/hidden, last edited, unpublished changes (peach) |
| **Site → Hero … Footer** | One screen per section of the page |
| **Site → Projects** | The work grid. Drag rows to reorder; untick *Show on site* to hide |
| **Settings → Brand & SEO** | Name, email, location, clock timezone, availability, page title/description, share image |
| **Settings → Theme** | Colours (with a live WCAG readability check), fonts, corner radius |
| **Settings → Navigation & sections** | Section order and visibility, menu links, small interface labels |
| **Settings → Media** | Every image, with its alt text |

**Save draft** keeps a change private; **Publish changes** puts it live immediately. The eye icon opens a live preview beside the form that updates as you type (drafts included). There's also an editing guide at `/admin/guide`, linked from the sidebar's *Need help?* card.

## How it fits together

| Path | What it is |
| --- | --- |
| `src/globals/`, `src/collections/` | The content model (one global per section, plus Projects/Media/Users) |
| `src/lib/assemble.ts` | Admin data → the `content.json` shape in `site/SCHEMA.md` (also served at `/content.json`) |
| `src/lib/render.js` | Content → page HTML. Shared by the public page and the live preview |
| `src/lib/document.ts`, `src/app/(site)/route.ts` | The public page: full HTML incl. SEO/share tags; prerendered, refreshed on publish |
| `public/styles.css`, `public/site.js` | The site's styles and behaviour (clock, menu, reveals, count-up, parallax) |
| `src/app/(preview)/preview` | The live-preview pane (logged-in only) |
| `src/components/admin/`, `src/app/(payload)/admin.css` | The admin skin: sidebar, dashboard, guide, colour field, contrast check |
| `site/` | The original static build, kept for reference and as the seed source |

## Checking your work

With the server running:

```bash
node .shots/flow.mjs <outDir>                  # draft → preview → publish → revert, end to end
node .shots/admin.mjs <outDir> /admin …        # screenshots of admin pages
node .shots/diff.mjs a.png b.png diff.png      # pixel diff of two screenshots
```

These borrow Playwright from the portfolio project; they aren't dependencies here.
